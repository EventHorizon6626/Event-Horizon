# Event Horizon

An intelligent investment portfolio management platform powered by multi-agent AI architecture.

## Overview

Event Horizon is a financial investment aid application that helps clients make informed decisions about their investment portfolios through collaborative AI agents. The platform enables users to create and manage portfolios containing stocks, ETFs, equities, and other financial instruments, while receiving real-time analytical insights from specialized AI agents.

## Objective

The primary objective of Event Horizon is to democratize sophisticated investment analysis by providing retail investors with access to a multi-agent AI system that continuously monitors, analyzes, and provides actionable recommendations for portfolio optimization.

### Key Goals

1. **Accessible Investment Intelligence**: Provide institutional-grade portfolio analysis to individual investors
2. **Multi-Agent Collaboration**: Leverage specialized AI agents that work together to deliver comprehensive investment insights
3. **Customizable Analysis**: Allow users to select which agents analyze their portfolio based on their investment strategy and preferences
4. **Data-Driven Recommendations**: Provide evidence-based advice on portfolio allocation and rebalancing

## Core Features

### User Authentication & Portfolio Management
- **Google Account Integration**: Secure authentication via Google OAuth
- **Portfolio Creation**: Users can build custom portfolios by selecting from:
  - Stocks (individual equities)
  - ETFs (Exchange-Traded Funds)
  - Equity indices
  - Other financial instruments
- **Portfolio Distribution**: Define initial capital allocation across selected assets

### Multi-Agent Architecture

Event Horizon employs a sophisticated multi-agent system where each agent specializes in a specific aspect of financial analysis. Users can select which agents to activate for their portfolio analysis.

#### Available Agent Types

The platform supports various specialized agents, each focused on a specific analytical domain:

1. **News Analysis Agent**
   - Monitors real-time news feeds for each asset in the portfolio
   - Performs sentiment analysis on news articles
   - Identifies market-moving events and their potential impact

2. **Financial Summary Agent**
   - Aggregates key financial metrics
   - Tracks earnings reports and quarterly results
   - Monitors dividend announcements and corporate actions

3. **Report Analysis Agent**
   - Analyzes annual reports (10-K)
   - Processes quarterly reports (10-Q)
   - Extracts insights from management discussions and analyses (MD&A)

4. **Balance Sheet Agent**
   - Evaluates company financial health
   - Tracks key ratios (debt-to-equity, current ratio, etc.)
   - Identifies trends in assets, liabilities, and equity

5. **Technical Analysis Agent**
   - Reads and interprets price charts and patterns
   - Analyzes trading volume and momentum indicators
   - Identifies support/resistance levels and trend signals

6. **[Additional agents to be defined based on specific needs]**
   - Market correlation analysis
   - Risk assessment
   - Macro-economic indicators
   - Sector analysis
   - And more...

### Agent Collaboration & Recommendation Engine

The selected agents work collaboratively to:
1. **Collect Data**: Each agent gathers information from its specialized domain
2. **Analyze Independently**: Agents process their respective data and form individual assessments
3. **Collaborate & Synthesize**: Agents share insights and identify patterns across different data sources
4. **Generate Recommendations**: The multi-agent system produces unified advice on:
   - Portfolio rebalancing suggestions
   - Buy/sell/hold recommendations for individual assets
   - Optimal capital distribution across the portfolio
   - Risk assessment and mitigation strategies
