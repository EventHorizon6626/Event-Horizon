## 💻 Data Management Best Practices

### Storage:
- **Small**: SQLite (< 100 GB)
- **Medium**: PostgreSQL, TimescaleDB (< 1 TB)
- **Large**: ClickHouse, AWS S3 + Athena (> 1 TB)

### Python Libraries:
```python
# Data retrieval
import yfinance as yf
import polygon
from alpaca.data import StockHistoricalDataClient

# Storage
import pandas as pd
import sqlalchemy
import arctic  # MongoDB time-series

# Processing
import numpy as np
import polars  # Faster than pandas
```

### Workflow:
1. **Ingest**: Download data daily (cronjob)
2. **Clean**: Handle splits, dividends, bad ticks
3. **Store**: Database with proper indexing
4. **Access**: Fast retrieval for backtesting
5. **Monitor**: Data quality checks

## ⚠️ Data Quality Checklist

Before trading with data:
- ✅ Adjusted for splits and dividends?
- ✅ Point-in-time (no look-ahead bias)?
- ✅ Survivor-bias free?
- ✅ Validated against known events?
- ✅ Clean (no obvious errors)?
- ✅ Timezone handled correctly?
- ✅ Sufficient history for backtesting?
